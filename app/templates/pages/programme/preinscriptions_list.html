Guide des Préinscriptions

Qu'est-ce qu'une Préinscription ?

Une Préinscription est une demande d'inscription initiale effectuée par un candidat via un formulaire public, avant la validation et l'inscription définitive dans le programme.

Processus de Préinscription
1. Formulaire Public

Le candidat remplit un formulaire en ligne avec ses informations personnelles et professionnelles.

2. Validation

L'équipe du programme examine la préinscription et vérifie l'éligibilité du candidat.

3. Inscription

Si validée, la préinscription devient une inscription définitive et le candidat intègre le programme.

4. Suivi

Les statistiques permettent de suivre le nombre de préinscriptions par statut et par période.

Informations Collectées
  • Données personnelles : Nom, prénom, email, téléphone
  • Informations professionnelles : Entreprise, secteur d'activité, fonction
  • Localisation : Adresse, ville, code postal
  • Motivation : Raisons de l'intérêt pour le programme
Conseils
  • Vérifiez régulièrement : Consultez les nouvelles préinscriptions fréquemment
  • Validez rapidement : Traitez les demandes dans les meilleurs délais
  • Suivez les statistiques : Analysez les tendances pour améliorer le recrutement
  • Contactez les candidats : Prenez contact avec les préinscrits pour confirmer leur intérêt
